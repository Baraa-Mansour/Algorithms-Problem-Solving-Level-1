# Algorithms & Problem-Solving – Level 1

This project is a beginner-level C++ practice workspace focused on programming fundamentals, clean code, and problem-solving.

## What this project is about

It is designed to help train and improve skills in:

- Programming fundamentals
- Writing clean and readable C++ code
- Problem-solving techniques
- Divide-and-conquer thinking
- Building confidence with algorithmic challenges

## Level

This repository represents Level 1 of the learning journey.

## How to run

1. Open the solution file named "Algorithms & Problem-Solving – Level 1.sln" in Visual Studio.
2. Build the project.
3. Run the program using F5 or the Run button.

## Topics covered in main.cpp

The code in main.cpp includes practice on:

- Input and output with C++
- Variables, data types, and strings
- Functions and return values
- Conditional statements
- Loops: while, do-while, and for
- Structures and enums
- Basic arithmetic and calculations
- Math problems such as area, power, factorial, and averages
- Prime number checking
- Time duration conversion
- Simple login and PIN validation exercises

## Tech Stack

- C++
- Visual Studio project files

## Purpose

The main goal is to practice solving problems and strengthening core programming concepts through simple and structured exercises.
